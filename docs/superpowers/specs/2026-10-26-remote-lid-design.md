# 원격지킴이 1.1 설계

## 승인 범위

기존 Swift/AppKit 앱의 토글, 전원 경고, 이전 설정 복원, 오류 복구를 개선합니다. 정적 다운로드 페이지와 개인 GitHub 등록용 문서를 준비합니다. Git 상태 변경과 외부 발행은 별도 승인을 받습니다.

## 앱 동작

- 토글은 실제 SleepDisabled 값을 표시합니다. 변경 중 중복 입력을 막습니다.
- 최초 켜기 직전 설정을 기존 형식 restore.json에 원자적으로 보관합니다. 비밀번호와 경고 승인 이력은 저장하지 않습니다.
- MacBook에서 충전기 미연결 또는 배터리 20% 이하이면 취소를 기본값으로 한 승인 창을 표시합니다. 전원 상태를 읽을 수 없으면 켜지 않습니다.
- 실행 중 위험 상태가 바뀌면 한 번 안내하고 사용자가 유지 또는 복원을 선택합니다. 경고 중복 방지 상태는 메모리에만 둡니다.
- 끄기는 앱이 실제 바꾼 AC 항목과 SleepDisabled를 복원합니다. 다른 곳에서 바꾼 비관리 항목은 보존합니다. 관리 항목에 예상 밖 값이 있으면 덮어쓰기 전에 확인합니다.
- 관리자 명령 직전 현재 값을 다시 확인합니다. 명령 실패 시 변경 직전 값으로 복구를 시도하고, 실패 여부는 실제 상태로 확인합니다.
- 복원이 확인된 뒤에만 기록을 삭제합니다. 최초 인증 취소로 설정이 바뀌지 않은 것이 확인되면 새 기록을 제거합니다.
- 손상된 복원 기록은 보존합니다. 사용자 승인 후 SleepDisabled만 긴급 해제할 수 있고, 전체 복원으로 안내하지 않습니다.
- 상태 조회는 별도 직렬 큐에서 수행하고 외부 프로세스 대기 시간을 제한합니다. 관리자 인증 창은 macOS가 담당합니다.

## 페이지

별도 프레임워크 없이 HTML/CSS/JavaScript로 제작합니다. 짙은 남색, 밝은 본문, 민트색 상태 표시와 실제 앱을 닮은 토글 미리보기를 사용합니다. 제목, 다운로드, 주요 기능, 설치, 안전 안내, 질문 순서로 구성합니다. 다운로드는 로컬 검토 단계에서 실제 빌드 ZIP으로 연결합니다. 저장소와 공개 범위 확정 후 GitHub Releases와 Pages 연결을 준비합니다.

## 검증과 제한

기존 --self-test에 전원 경계값, 잘못된 입력, 복원 소유 항목, 외부 변경, 모의 명령의 실패 복구, 시간 제한 검사를 추가합니다. 빌드·서명 검사와 로컬 페이지 콘솔·실패 요청만 확인합니다. 실제 전원 변경과 덮개 닫기, 개발자 인증서·공증 및 외부 발행은 수행 결과와 승인 여부를 별도로 기록합니다.

## Mac 공통 지원 추가 승인

저장소 이름은 `KangUnMo/mac-remote-lid`로 정리합니다. Apple Silicon MacBook·Mac mini·Mac Studio 등의 시스템·유휴 잠자기 방지와 복원을 지원하도록 전원 조회를 보완합니다. 배터리 유무는 IOPowerSources API로 확인하며, 조회 실패와 정상적인 내장 배터리 없음을 구분합니다. 배터리·덮개 표시는 MacBook에만 적용합니다. 데스크톱에는 배터리 경고를 표시하지 않습니다. 저장 형식과 복원 명령은 유지합니다.

페이지와 사용 안내에서 공통 기능과 MacBook 전용 기능을 구분합니다. 기종별 모의 검사와 실제 현재 Mac의 읽기 검사를 수행합니다. 데스크톱 실기기, 24시간 연속 동작, Intel 지원과 외부 발행은 완료로 표시하지 않습니다.
