# 원격지킴이 1.1.7

화면 자동 꺼짐 진단을 실제 조회 범위에 맞게 수정하고, 터미널 설치의 검증과 실패 복구를 보강했습니다. Apple Silicon·macOS 13 이상을 지원하며 빌드 번호는 9입니다.

## 개선 및 수정

- **화면 진단:** ‘화면 자동 꺼짐 정상’과 ‘화면 안 꺼짐 원인’ 대신 감지된 방지 요청을 표시합니다. 마지막 조회 시각을 추가하고 미조회·조회 실패·요청 없음을 구분합니다. `Capturing`은 앱이 제공한 사유이며 실제 캡처 대상을 확정하지 않습니다.
- **설치 보호:** 실행 중인 앱을 강제 종료하지 않고 정상 종료를 안내합니다. ZIP SHA-256, 앱 식별자·버전·실행 파일·서명 무결성을 확인한 뒤 기존 앱을 백업하고 교체합니다. 교체·실행 요청 실패 시 복구를 시도하고, 복구 실패 시 백업을 보존합니다.
- **업데이트 선택:** 초안·시험판과 잘못된 태그·ZIP 이름·주소를 제외합니다. 앞쪽 후보가 잘못돼도 이후의 유효한 정식 버전을 선택합니다.
- **네트워크 표시:** 인터페이스 이름만으로 Wi-Fi·이더넷·VPN을 단정하지 않고 ‘네트워크 (인터페이스명)’으로 표시합니다.
- **설치 호환성:** macOS 기본 Bash 3.2를 지원하고, 격리 해제 시 `com.apple.quarantine`만 처리하여 다른 확장 속성을 보존합니다.
- **문서:** 설치·보안 안내와 다운로드 링크를 실제 구현 및 1.1.7에 맞췄습니다.

## 확인한 내용

- 임시 폴더와 모의 명령을 사용한 설치 성공·실패·복구 21개 상황을 검사했습니다.
- Swift 자체검사, 컴파일, 로컬 서명, ZIP 내부 버전과 SHA-256 검사를 통과했습니다.
- 로컬 Mac에서 새 앱 설치 후 원격 모드 켜기·끄기와 이전 전원 설정 복원을 확인했습니다. 공개 다운로드 설치 스크립트로 설치한 검사는 아닙니다.
- 실제 화면 자동 꺼짐, 덮개를 닫은 상태의 장시간 연결은 아직 검증하지 않았습니다.

## 업데이트 안내

기존 앱을 교체하기 전에 원격 모드를 끄고 메뉴에서 정상 종료해 주세요. 설정 복원 중 Mac이 잠자기에 들어가 원격 연결이 끊길 수 있습니다. 업데이트 후 원격 모드는 직접 다시 켜 주세요.

1.1.2에서 업데이트하는 경우 먼저 원격 모드를 꺼 주세요. 이전 버전의 업데이트 결함은 새 릴리스 게시만으로 수정되지 않습니다.

Apple Developer ID 서명과 공증은 적용되지 않은 로컬 서명 빌드입니다. SHA-256과 서명 검사는 파일·번들 무결성을 확인하며 배포자 신원이나 공증을 보장하지 않습니다.
