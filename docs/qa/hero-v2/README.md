# 히어로 V2 검증 기록

2026-10-26, ego lite에서 로컬 검증 페이지를 직접 조작했습니다. 현재 공개 사이트의 이전 화면을 비교용으로 저장했습니다. 이번 변경의 커밋과 배포는 별도 승인이 필요합니다.

## 변경 내용

기존 CSS 노트북 그림을 투명 배경의 새 제품 렌더로 교체했습니다. 내장 image_gen으로 제작했으며 [전체 프롬프트](image-prompt.md)를 보관했습니다. 제품 렌더는 실제 제품 사진이 아닌 시각화입니다.

- 데스크톱: `website/assets/mac-hardware-hero-v2.webp`, 1536 × 1024, 88,444바이트.
- 모바일: `website/assets/mac-hardware-hero-v2-mobile.webp`, 960 × 640, 42,590바이트.
- HTML 앱 창을 제품 위에 배치해 텍스트와 토글을 직접 조작할 수 있습니다.
- 데스크톱에서는 장면 고정, 제품 이동·확대·회전, 앱 창의 별도 이동, 제목 페이드와 진행 막대를 적용했습니다.
- 모바일과 높이가 짧은 화면에서는 장면 고정을 해제합니다. 동작 줄이기 설정에서는 모든 장면 변형을 해제합니다.

## 실제 검증 결과

| 항목 | 관찰 결과 |
| --- | --- |
| 1440 × 900 데스크톱 | 제품의 세로 변형 79.939 → -80px, 약 159.94px 이동 |
| 앱 창 | 75.9588 → -32px, 약 107.96px 이동, 모든 측정 지점에서 패널 안에 표시 |
| 제품 확대 | 0.9001 → 1.1200 |
| 장면 고정 | 스크롤 704 → 1524px 동안 패널 위쪽 약 90px 유지 |
| 제목 겹침 방지 | 마지막 지점에서 제목 불투명도 0 |
| 390 × 844 모바일 | 장면 고정 없음, 작은 이미지 로드, 가로 넘침 없음 |
| 모바일 이동 | 화면에 보이는 세 지점의 제품 변형 6.68 → -8.12px. 이 구간은 전체 진행도 약 0.36 → 0.67에 해당 |
| 768 × 1024 태블릿 | 세로 배치와 패널 표시를 스크린샷으로 확인, 가로 넘침 없음 |

| 1440 × 650 짧은 화면 | 가로 넘침 없음, 장면 고정 없음 |
| 토글 클릭 | 잠자기 방지 해제됨, 이전 설정 복원 완료 표시 |
| 키보드 Space | 다시 켜짐으로 전환 |
| 동작 줄이기 | 제품·앱 창 transform 없음, 정적 높이 720px, 진행 막대 숨김. 설정 해제 후 모션 재개 |
| 콘솔·네트워크 | 로컬 페이지 재진입부터 수집한 오류와 실패 요청 없음 |

휠 입력으로 스크롤하고 실제 DOM 변형과 위치를 측정했습니다. 제품 이동량은 문서 스크롤량이 아닌 CSS transform의 세로 이동량입니다. 브라우저 자동화의 화면 크기 에뮬레이션으로 검사했으며 실제 휴대폰과 GPU별 프레임 성능은 측정하지 않았습니다.

다운로드 버튼을 눌러 ZIP을 실제 저장했습니다. 파일명은 `remote-lid-1.1.0-arm64.zip`, 크기는 976,132바이트이며 기존 배포 파일의 SHA-256과 일치했습니다.

```text
92fff17a3e58490baedaff27a49f6e3e6fbc0b88b4158d36a8fbec5e272d7e9f
```

검증 중 발견한 앱 창 오른쪽 잘림, 마지막 장면의 제목 겹침, 모바일 미디어 쿼리 중괄호 문제를 수정한 후 다시 검사했습니다. JS 문법, HTML id 중복, 정적 자원 경로, CSS 중괄호와 diff 공백 검사도 통과했습니다.
