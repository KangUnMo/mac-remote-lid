# 승인 범위와 구현 계획

사용자가 승인한 계획을 PM으로부터 위임받았습니다. 비TDD로 구현한 뒤 기존 자체검사를 확장합니다.

- `install.sh`: 실행 중 앱 정상 종료 안내 후 중단, SHA-256·번들·서명 검증, 같은 설치 폴더에서 준비·백업·교체·실패 복구와 백업 보존을 적용합니다.
- `Source/main.swift`: 화면 요청의 관찰 결과와 메모리 조회 시각을 표시하며 정식 업데이트 후보 검증과 중립적인 네트워크 이름을 적용합니다. 기존 저장·SSH 선택 방식·1.1.6 버전은 유지합니다.
- `README.md`, `사용안내.md`: 현재 버전·다운로드와 진단·설치·보안 정책을 구현에 맞춥니다.
- `Source/test-install.py`: 임시 경로와 모의 외부 명령으로 설치 경로를 검사합니다.
- `docs/qa/2026-11-05-review-fixes/`: 계획과 명령별 검증 결과를 기록합니다.

## 검사 안전성

`Source/build.sh`와 `selfTest()`를 실행 전에 읽었습니다. 빌드는 임시 앱과 프로젝트의 무시된 빌드·다운로드 결과물을 작성합니다. 자체검사는 전원 명령을 모의 함수로 바꿔 실행하고 실제 전원 조회와 AppleScript 컴파일만 수행합니다. 관리자 인증과 실제 전원 설정 변경은 수행하지 않습니다. 설치 검사는 스크립트 복사본의 설치 경로를 임시 폴더로 바꾸고 다운로드·압축·서명·앱 조회·실행·격리 해제·관리자 명령을 모의 명령으로 바꿉니다.

## PM 확인

기존 `xattr -cr`을 `xattr -dr com.apple.quarantine`으로 축소하는 의도를 질문했고, PM은 기존 격리 해제 의도를 유지하고 다른 확장 속성을 보존하는 범위로 승인했습니다. 실제 앱에는 이 명령을 실행하지 않습니다.

## 제외

실제 설치·배포·업로드·브라우저·앱 종료·전원 변경·관리자 인증·로그인 설정 변경·Git 상태 변경·AWS CLI는 수행하지 않습니다. `.agents/`, `docs/brand/`와 기존 저장 로직은 수정하지 않습니다.
