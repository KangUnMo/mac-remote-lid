# 원격지킴이 1.1.8

화면 꺼짐 방지 요청 목록과 한글 줄바꿈을 개선했습니다. Apple Silicon·macOS 13 이상을 지원하며 빌드 번호는 10입니다.

## 변경 내용

- 마지막 조회 시각을 목록에서 새로고침 버튼 도움말로 옮겼습니다. 버튼에 마우스를 올리면 확인할 수 있습니다.
- 앱 이름·PID·요청 사유를 먼저 보여주고 긴 안내문을 하단의 짧은 설명으로 정리했습니다.
- 상세 정보에 일반 시스템 글꼴과 한글 단어 우선 줄바꿈을 적용했습니다. 현재 설정·이전 설정 탭에도 적용됩니다.
- 상세 내용이 바뀌면 첫 항목부터 표시하여 긴 요청에서도 앱 이름을 먼저 확인할 수 있습니다.
- 60초마다 macOS 전원 요청을 확인한다는 목적을 안내합니다. 조회 주기와 전원 설정·복원 동작은 유지합니다.

## 업데이트 방법

기존 앱의 메뉴 막대 메뉴에서 **업데이트 확인…**을 선택해 주세요. 업데이트 과정에서 원격 모드가 켜져 있으면 먼저 전원 설정 복원을 진행합니다. 이때 Mac이 잠자기에 들어가 원격 연결이 끊길 수 있습니다. 업데이트 후 원격 모드는 직접 다시 켜 주세요.

Apple Developer ID 서명과 공증이 없는 로컬 서명 빌드입니다. SHA-256과 로컬 서명 검사는 파일·번들 무결성을 확인하며 Apple 공증을 대신하지 않습니다.

## 검증

- Swift 자체검사와 arm64 빌드, 로컬 서명 검사를 통과했습니다.
- 설치 성공·실패·복구의 모의검사 21개 상황을 통과했습니다.
- 별도 검증 창에서 앱 목록, 요청 없음, 조회 실패, 미조회, 긴 요청 사유, 현재·이전 설정 표시를 확인했습니다.
- 설치된 앱의 실제 업데이트는 사용자가 진행합니다. 실제 화면 자동 꺼짐과 장시간 덮개 동작은 이번 변경의 검증 범위에 포함하지 않았습니다.
