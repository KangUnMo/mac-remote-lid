# 원격지킴이 1.1.1 미리보기

Apple Silicon Mac과 macOS 13 이상을 대상으로 하는 개인용 메뉴 막대 앱입니다. 앱 버전은 1.1.1, 빌드 번호는 3입니다.

## 다운로드

- [다운로드 페이지](https://KangUnMo.github.io/mac-remote-lid/)
- [앱 ZIP](https://github.com/KangUnMo/mac-remote-lid/releases/download/v1.1.1/remote-lid-1.1.1-arm64.zip)
- [SHA-256 확인 파일](https://github.com/KangUnMo/mac-remote-lid/releases/download/v1.1.1/remote-lid-1.1.1-arm64.zip.sha256)

## 변경 내용

- 메뉴 막대 아이콘 중앙 도트를 잠자기 방지 켜짐은 초록색, 꺼짐은 빨간색, 상태 확인 불가는 회색으로 표시합니다.
- 아이콘 테두리는 macOS 템플릿 렌더링을 유지해 밝은 화면과 어두운 화면에 대응합니다. 색상 도트는 메뉴 클릭을 가로막지 않습니다.
- ‘SSH 접속 허용 설정…’ 메뉴로 시스템 설정의 공유 화면을 엽니다. 원격 로그인과 허용할 사용자는 사용자가 직접 선택합니다. SSH를 자동으로 켜거나 끄지 않습니다.
- 다운로드 페이지와 README에 최초 실행 차단 시 허용 절차를 추가했습니다.

## 최초 실행

이 빌드는 로컬 임시 서명을 사용하며 Apple Developer ID 서명과 공증은 적용되지 않았습니다. 출처와 파일 무결성을 확인하고 신뢰하는 경우에만 실행해 주세요.

1. ZIP을 풀고 앱을 응용 프로그램 폴더로 옮깁니다.
2. 앱을 열어 본 뒤 실행 차단 경고가 나오면 ‘완료’를 선택합니다.
3. 시스템 설정 → 개인정보 보호 및 보안에서 원격지킴이의 ‘그래도 열기’를 누르고 인증합니다.
4. 다시 나타나는 창에서 ‘열기’를 선택합니다.

[Apple 공식 안내](https://support.apple.com/ko-kr/102445)에 따른 앱별 실행 예외입니다. Gatekeeper 전체 비활성화나 격리 속성 제거는 필요하지 않습니다.

## 업데이트

기존 앱에서 원격 모드를 끄고 종료한 뒤 새 앱으로 교체합니다. 끄는 동안 Mac이 잠자기에 들어가 원격 연결이 끊길 수 있습니다. 복원 기록을 임의로 삭제하지 마세요.

## 확인 범위와 제한

빌드와 기존 자체 검사, 밝은 화면·어두운 화면의 도트 색상 렌더링, 클릭 통과, 로컬 서명 무결성, ZIP 무결성과 버전·실행 파일 일치를 검사했습니다. macOS 26.3.1에서 설정 URL이 공유 화면을 열고 원격 로그인 항목을 표시하는 것을 확인했습니다. SSH 스위치는 변경하지 않았습니다.

다운로드 페이지의 JavaScript 문법, 내부 앵커, 새 버전 다운로드 링크 3개와 최초 실행 안내를 검사했습니다. 에고에서 로컬 페이지를 다시 불러와 콘솔 오류와 실패한 네트워크 요청이 없는 것을 확인했습니다. 공개 파일의 다운로드 검증은 릴리스 발행 후 수행합니다.

실행 중인 기존 앱을 종료하거나 교체하지 않았습니다. 새 앱이 실행된 실제 메뉴 막대에서의 색상 표시, 관리자 인증을 거친 켜기·끄기, 데스크톱 Mac 실기기와 24시간 연속 동작은 이번 릴리스에서 확인하지 않았습니다. macOS 버전에 따라 설정 화면 이동은 달라질 수 있습니다.
