# 원격지킴이 1.1.0 미리보기

Apple Silicon Mac과 macOS 13 이상을 대상으로 하는 개인용 메뉴 막대 앱입니다.

## 다운로드

- [다운로드 페이지](https://KangUnMo.github.io/mac-remote-lid/)
- `remote-lid-1.1.0-arm64.zip`: 앱 ZIP
- `remote-lid-1.1.0-arm64.zip.sha256`: ZIP의 SHA-256 확인 파일

## 주요 기능

- 실제 시스템 상태를 표시하는 토글과 이전 전원 설정 복원을 제공합니다.
- MacBook의 충전기 미연결·배터리 20% 이하 상태에서는 켜기 전에 추가 승인을 받습니다.
- 내장 배터리가 없는 데스크톱 Mac의 전원 처리와 공통 복원 경로를 지원합니다.
- 인증 취소, 부분 실패, 손상된 복원 기록에 대한 복구 경로를 보완했습니다.

## 확인 범위와 제한

빌드·자체 검사·로컬 서명 무결성·ZIP 검사를 통과했습니다. 데스크톱 전원 처리와 실패 복구는 모의 명령으로 검사했으며, 실제 관리자 인증을 거친 켜기·끄기와 데스크톱 실기기·24시간 연속 동작 검증은 수행하지 않았습니다.

이 빌드는 로컬 임시 서명을 사용합니다. Apple Developer ID 서명과 공증은 적용되지 않아 macOS가 실행을 차단할 수 있습니다. 보안 기능을 끄지 마세요. MacBook은 충전기를 연결하고 통풍되는 곳에서 사용하며, 가방에 넣기 전에 원격 모드를 꺼 주세요.
