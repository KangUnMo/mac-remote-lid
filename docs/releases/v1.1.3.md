# 원격지킴이 1.1.3

## 변경 사항

- 제어 창과 메뉴에 화면 꺼짐 방해 앱 이름, PID, 요청 사유를 표시합니다.
- 60초 주기와 수동 새로고침으로 갱신하고 조회 실패와 요청 없음을 구분합니다.
- 시스템 잠자기 방지는 별도로 취급하며, 배터리 경고 후 사용자가 선택하는 기존 동작을 유지합니다.
- 원격 모드가 켜져 있을 때 업데이트 복원이 자체 작업 가드에 막히던 문제를 수정했습니다.
- 업데이트 ZIP의 SHA-256과 앱 식별자·버전·서명 무결성을 확인합니다.
- 새 앱 준비 후 기존 프로세스 종료를 기다리고, 기존 앱을 백업한 뒤 교체합니다. 교체·실행 요청 실패 시 복원을 시도합니다.

## 설치와 업데이트

Apple Silicon, macOS 13 이상을 지원합니다. 앱 ZIP과 SHA-256 파일을 함께 제공합니다.

**1.1.2에서 업데이트하려면 원격 모드를 먼저 끄고 메뉴의 ‘업데이트 확인…’을 선택해 주세요.** 기존 1.1.2의 업데이트 결함은 새 릴리스 게시만으로 수정되지 않습니다. 끄는 동안 원격 연결이 끊길 수 있으며, 관리자 인증은 직접 진행해야 합니다. 업데이트 후 원격 모드는 직접 다시 켜 주세요.

모니터링 결과는 저장하거나 전송하지 않습니다. 업데이트용 임시 앱 백업은 성공 후 정리하며 복원 실패 시 보존합니다.

개인용 로컬 서명 빌드이며 Developer ID 서명과 Apple 공증은 없습니다. 체크섬과 로컬 서명 무결성 확인은 개발자 신원 인증이나 공증을 대신하지 않습니다. 앱 실행 요청 성공은 장시간 정상 동작을 보장하지 않습니다.
