궁금한 점이 있나요?

왜 관리자 인증이 필요한가요?

macOS의 시스템 전원 설정을 변경하기 위해 필요합니다. 인증은 macOS가 처리하며, 원격지킴이는 비밀번호나 관리자 권한 상주 도우미를 보관하지 않습니다.

어떤 정보가 저장되나요?

이전 전원 설정과 저장 시각을 Mac의 Application Support/RemoteLid/restore.json에 보관합니다. 복원이 확인되면 삭제합니다. 최초 사용 안내 확인 여부도 Mac에 저장합니다. 별도 계정이나 외부 서버 전송 기능은 없습니다.

배터리가 부족하면 자동으로 꺼지나요?

배터리 경고는 MacBook에 적용하며 자동으로 끄지는 않습니다. 켜기 전 배터리가 20% 이하이거나 충전기가 없으면 승인을 받습니다. 켜진 뒤 위험 상태가 바뀌면 다시 안내하고, 유지하거나 끄고 복원할 수 있습니다.

앱이 강제로 종료되면 어떻게 하나요?

앱을 다시 열고 이전 설정 복원을 선택해 주세요. 복원 기록을 임의로 지우지 마세요. 기록이 손상된 경우 긴급 해제는 잠자기 방지만 끄며, 이전 설정 전체를 복원하지는 못합니다.

Mac mini·Mac Studio도 계속 켜둘 수 있나요?

시스템·유휴 잠자기 방지는 데스크톱 Mac에서도 사용할 수 있습니다. 내장 배터리와 덮개가 없는 Mac에서는 해당 표시와 배터리 승인을 생략합니다. 동작 시간 제한은 두지 않지만, 정전·재시동·시스템 종료를 막지는 않습니다.

Intel Mac과 원격 연결도 지원하나요?

현재 빌드는 Apple Silicon MacBook·Mac mini·Mac Studio 등과 macOS 13 이상을 대상으로 합니다. Intel용 빌드는 제공하지 않습니다. 원격 연결은 사용하시는 프로그램에서 별도로 설정해 주세요. 24시간 연속 동작과 MacBook의 덮개를 닫은 상태의 연결 유지는 사용 환경별 확인이 필요합니다.
